3
Upload File Konfigurasi
next.config.js — pengaturan Next.js
①

Dari halaman repository, tap "Add file" → "Create new file" lagi

②

Di kolom nama file, ketik: next.config.js

③

Tempel kode berikut di area konten:

next.config.js
/** @type {import('next').NextConfig} */ const nextConfig = {} module.exports = nextConfig
④

Scroll bawah → tap "Commit changes"

⚠️
Sekarang kamu perlu buat folder di dalam repository. Di GitHub HP, caranya dengan menulis nama folder + garis miring di nama file. Langkah berikutnya akan jelaskan ini.

src/app/layout.js
